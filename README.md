# Conditions: Взлом Системы
Прототип мобильного приложения для изучения темы «Условия (IF/ELSE)» в игровом формате.

## 📱 О проекте
Приложение создано в рамках Всероссийского хакатона «ИТ-Прорыв» в номинации «Мобильная разработка». 
Оно знакомит подростков 12–17 лет с базовой темой программирования — «Условия (IF/ELSE)» — через игровую механику «взлома системы».

## 🎮 Игровая механика
*   **Байты** — начисляются за правильные ответы.
*   **Тревога** — растет при ошибках.
*   **Карта узлов** — открывает новые уроки по мере прохождения.

## 🛠️ Использованные технологии
*   **Платформа:** MIT App Inventor
*   **Хранение данных:** TinyDB (локальное сохранение прогресса)
*   **Язык:** визуальные блоки

## 🚀 Как запустить прототип
1. Скачайте файл `Conditions.aia` из этого репозитория.
2. Откройте [MIT App Inventor](http://ai2.appinventor.mit.edu/).
3. Нажмите `Projects` -> `Import project (.aia) from my computer`.
4. Выберите скачанный файл.
5. Нажмите `Build` -> `Android App (.apk)` для сборки установочного файла или `Connect` -> `AI Companion` для тестирования на телефоне.
